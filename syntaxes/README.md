# Rino Language Support for VSCode

> دعم لغة **Rino** العربية في محرر VSCode

![Rino](icon.png)

## ✨ الميزات

- 🎨 **تلوين الأكواد** — كل الكلمات المفتاحية ملونة
- 📝 **إكمال تلقائي** — قوالب جاهزة لـ `صفحة`, `دالة`, `إذا`, إلخ
- 🌐 **دعم RTL** — النص العربي يظهر بشكل صحيح
- 🔧 **إغلاق تلقائي** للأقواس والاقتباسات
- 💬 **تعليقات** بخط `//`

## 📦 التثبيت

### الطريقة 1: من ملف VSIX (الأسهل)

1. حمّل الملف `rino-language-support-0.3.0.vsix` من قسم [Releases](../../releases)
2. افتح VSCode
3. اضغط `Ctrl+Shift+X` (نافذة Extensions)
4. اضغط `...` في الأعلى
5. اختر **Install from VSIX...**
6. اختر الملف

### الطريقة 2: النسخ اليدوي

1. حمّل المستودع (زر Code → Download ZIP)
2. فك الضغط
3. انسخ المجلد إلى:
   - **Windows:** `%USERPROFILE%\.vscode\extensions\rino-lang.vscode-rino-0.3.0`
   - **Mac/Linux:** `~/.vscode/extensions/rino-lang.vscode-rino-0.3.0`
4. أعد تشغيل VSCode

## 🚀 الاستخدام

افتح أي ملف `.rino` — ستُفعّل الميزات تلقائيًا.

إذا لم تُفعّل، اضغط `Ctrl+Shift+P` → اكتب `Change Language Mode` → اختر **Rino**.

## 💡 مثال

```rino
صفحة("مرحبًا")

حالة {
    دع العداد = 0
}

جسم {
    فقرة("العداد: " + سلسلة(العداد))
    زر("زيادة") {
        عند_الضغط {
            العداد = العداد + 1
        }
    }
}
